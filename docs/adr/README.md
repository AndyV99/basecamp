# Architecture Decision Records

One file per decision, `NNNN-short-title.md`, numbered sequentially and never
renumbered. Status is `proposed`, `accepted`, or `superseded by NNNN`; a
superseded record is kept, not deleted, because the reason for changing course
is itself worth having.

A decision belongs here when it's expensive to reverse: a host, a datastore, a
GitOps tool, a policy engine, a boundary between layers. Reasoning that lives
only in a PR thread or a chat is lost reasoning.
